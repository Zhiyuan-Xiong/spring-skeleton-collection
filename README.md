## 项目目标

SPRING 是以 Remake 服装与实验性首饰设计为核心的亚文化服饰品牌。项目期间，我参与品牌视觉设计、Logo 设计以及「骨骸系列（Skeleton Collection）」3D 打印首饰开发，构建从品牌视觉到产品设计的完整创作体系。

## 我的贡献

品牌视觉、Logo 设计与骨骸系列 3D 打印首饰开发

完成阶段：品牌视觉、首饰造型与三维可视化

现有产出：SPRING 字标、品牌视觉、首饰造型与佩戴渲染

## AI 与制作工作流

### 1. 品牌与形态约束

围绕 SPRING 的亚文化定位，提炼骨骸、金属、身体结构与哥特视觉语言，确定首饰系列和品牌识别方向。

### 2. AI 图片构思

使用 **Midjourney** 探索骨骼形态、材质氛围与佩戴视觉，筛选能延续 SPRING 品牌语言的图像方向。

### 3. AI 辅助建模

使用 **Tripo 3D** 将选定图像与形态方向转为三维初始模型，作为后续雕刻和细化的基础。

### 4. 人工细化

在 **ZBrush 与 Nomad** 中进行人工雕刻、形体修正与细节调整；结合佩戴关系、比例和制作需求继续优化，让首饰形成统一的系列表达。

### 5. 最终输出与效率

Midjourney 加快视觉方向探索，Tripo 3D 提供可继续编辑的基础形体；ZBrush 与 Nomad 用于人工把控造型、结构与最终细节。减少重复的早期形态尝试，把时间集中在品牌一致性和首饰质量上。
