## 项目目标

SPRING 是以 Remake 服装与实验性首饰设计为核心的亚文化服饰品牌。项目期间，我参与品牌视觉设计、Logo 设计以及「骨骸系列（Skeleton Collection）」3D 打印首饰开发，构建从品牌视觉到产品设计的完整创作体系。

## AI 与制作工作流

### 1. 品牌与形态约束

围绕 SPRING 的亚文化定位，提炼骨骸、金属、身体结构与哥特视觉语言，确定首饰系列和品牌识别方向。

### 2. AI 图片构思

利用 AI 探索骨骼形态、材质氛围和佩戴视觉，筛选能承接系列语言的图像方向。此环节依据作者补充的制作过程。

### 3. AI 辅助建模

把选定图像与形态方向用于 AI 辅助三维建模，得到可供继续编辑的初始形体；具体工具与原生生成记录尚未随当前材料提供。

### 4. 人工细化

人工调整结构、表面与细节，并结合佩戴关系、比例与制作需求继续优化，让首饰形成统一的系列表达。

### 5. 最终输出与效率

将早期形态探索和基础形体制作交给 AI 辅助，把精力集中于品牌一致性、可佩戴结构和最终细节。仓库展示已公开的首饰渲染与品牌设计，未添加未经记录的效率百分比。
